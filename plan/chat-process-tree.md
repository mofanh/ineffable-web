# 对话过程树与工具行

状态：Active，2026-11-10；基线 a2d5eae。用户同意基于 Copilot 截图的展示层迭代。

## 合同

- 使用现有 AssistantEntry/segment、有序 WebNode、唯一 registry 与每 pane 一个 ChatRowWindow。
- 展开的过程以细主干、分支和缩进呈现；同一阶段内的工具形成连续叶子行，正文仍有清晰阅读宽度。
- 展示树只表达既有顺序和过程归属，不生成执行 DAG、计划步骤、额外语义摘要或新的状态权威。
- 保留新正文首字符自动收起、成功且 canonical 接管与明确 final 后总折叠、失败/取消/等待/暂停展开，以及原有焦点、选区、手动偏好规则。
- 原生正文、异常、活动工具、人工操作、图片、产物、插件/fallback 与完整最终答复保持既定可见性。结构化布局不改变 nodeId、原始顺序、恢复游标和输入边界。
- 工具行动与目标复用 tool-call-presentation；文件/路径与命令使用紧凑标签，图标表达操作类型。原始参数和结果仍可展开，目标纯文本不成为未经鉴权的文件链接。
- 成功工具的状态可弱化为有可访问文字的图标；执行中、错误、未知结果和终端“观察已返回”仍须明确区分，不能把 API 返回当命令成功。
- 只在前端实施；保留用户 Dockerfile.source/design.md、私密配置及后端未提交改动。沿用前端当前分支，本地提交；不推送、部署、调用模型或运行 GitHub Actions。
