# 左侧栏系统管理导航优化

目标：让管理员在不挤占工作区树空间的前提下，快速识别、展开和进入系统管理页面；保持现有权限、路由与侧栏组件边界不变。

## Phase 1：导航交互收敛

- [x] 系统管理仅在当前位于系统路由时默认展开，其他页面保留紧凑单行入口。
- [x] 系统管理父项只负责展开或收起，管理子项负责页面跳转，消除一次点击的双重意图。
- [x] 当前系统路由进入时自动展开，同时允许管理员主动收起。
- [x] 侧栏折叠为图标栏时，系统管理入口可直接回到当前管理页或默认管理页。
- [x] 移动端选择具体管理页后关闭侧栏抽屉。
- [x] 使用现有 `SidebarMenuSub` 层级和语义 token，不新增共享组件或业务硬编码文案。

### 验收标准

- 非系统页面默认只展示一行“系统管理”，不持续占用四个子项的高度。
- 点击“系统管理”不会意外跳转；点击任一子项只执行对应导航。
- 当前管理页有且只有子项作为主要选中态，父项收起后仍能表达所在分组。
- 图标栏与移动端入口均可完成导航。
