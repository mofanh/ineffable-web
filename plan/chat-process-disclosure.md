# 对话过程分段折叠

状态：Active，2026-11-10；前端基线 d808ae9。用户确认按已讨论方案实施。

## 展示合同

- 沿现有 ChatEntry/segment/WebNode/registry/timeline 处理，不复制消息、运行状态或渲染主路径。
- 新正文的首个非空内容出现后，收起此前已结束的思考、工具与更新；未结束工具、错误、待回答/审批、未知结果、待保存、图片/产物/插件 fallback 始终可见。
- 下一轮思考/工具只展开当前活动部分，前面正文仍可见。
- 当前输入范围成功完成、所有已加载片段正式接管、末段正文明确 final_answer 后，将此前阶段正文及过程归入一个总过程入口，保留完整最终答复。无可靠 final 标记保留正文。
- 失败/取消/暂停/等待不执行成功总折叠；不能按 EOF、最后 DOM 块或文本内容猜终态。
- 分组只是展示投影；不跨用户消息/人工回答边界，不丢弃正文。展开保持原顺序。
- 每个边界自动动作只执行一次，当前阶段手动偏好跨虚拟行重挂保留；完成态独立默认收起。焦点/选区暂缓自动收起，交互结束继续。
- 沿原单一滚动所有者与 ChatRowWindow，收起不产生双重补偿、强制滚到底或无限 DOM；不为每组新增滚动器/虚拟器。
