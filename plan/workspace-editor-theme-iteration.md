# 工作区文件编辑器主题适配迭代

## 目标

让工作区文件编辑器跟随应用当前实际生效的浅色或深色模式，并在用户选择“跟随系统”时响应系统主题变化。

## 边界

- 主题状态继续由现有 `next-themes` Provider 管理。
- 文件编辑器只消费 `resolvedTheme`，不创建独立主题状态或色板。
- 页面层继续负责组合文件加载、预览与编辑状态，不承担编辑器内部主题配置。

## Phase 1：编辑器明暗主题联动

- [x] 在 `WorkspaceCodeEditor` 中读取实际生效主题。
- [x] 将标准化后的 `light` / `dark` 主题传递给 CodeMirror。
- [x] 验证浅色、深色与跟随系统三种选择共用现有主题链路。

验收标准：

- 浅色模式下，CodeMirror 使用浅色编辑主题。
- 深色模式下，CodeMirror 使用深色编辑主题。
- “跟随系统”模式下，系统明暗变化会触发编辑器主题更新。
- 不新增硬编码业务文案或独立主题持久化状态。

自动验证：

- [x] `npm run i18n:check`
- [x] `npm run lint`
- [x] `npm run build`

手动验证：

- [ ] 打开可编辑文本文件，切换浅色、深色、跟随系统，确认编辑区背景、正文、行号与选区均保持可读。
